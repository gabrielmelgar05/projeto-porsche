# Image masters (not deployed)

Place master photographs here, one folder per section, named exactly as in
`docs/CODEX_IMAGE_ASSETS.md` — e.g. `assets-src/images/hero/gt3rs-hero-front34.png`.

Then run `npm run images`. It writes optimised AVIF + WebP variants to
`public/images/<dir>/` and marks each complete image as available.
